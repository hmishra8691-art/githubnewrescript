# Assets

**Research Tools → Assets** is the survey's media library: images, logos, video, audio, PDF and Office documents. Upload once, then **Choose** the file wherever media goes — question media, option images, the branding logo and background, or inside any text.

Upload limits: **25 MB** for pictures, **50 MB** for audio and documents, **200 MB** for video.

## When to use it

- A logo or background image for Branding.
- Images for image-choice options, or a video or audio clip as question media.
- A PDF or document for respondents to read.

## Set it up in the builder

::: steps Upload and use a logo
1. **Open Research Tools → Assets → Upload** — choose the file.
2. **Open Branding → Page & logo**.
3. **Logo → Choose** — pick the uploaded image.
4. **Set its size** with the logo controls.
:::

::: screen assets

## Common mistakes

- **Linking images from other websites** — they can change or disappear; upload them.
- **Large files on phones** — resize images before uploading; set the displayed size in the survey.

## Troubleshooting

- *An upload is refused* — check the size limit for its type.
