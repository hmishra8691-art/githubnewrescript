## What it does
Each project has its own collaborators with a role that decides what they can do (view, edit, manage data, analyse…). One person at a time holds the edit lock, so changes never overwrite each other; others can open the project read-only meanwhile.

## How to set it up
1. Open **Management** → **Collaborators**.
2. Click **+ Invite** and enter an **Email address or User ID** (for example USR-10482), choose their access and, optionally, an expiry.
3. Manage someone from their row: **Change access & expiry…**, **Make owner…**, **Remove access…**. **Pending invitations** can be resent.
4. **Access history** records every change.
5. Collaboration rules (whether an editor must hold the edit lock, read-only opening, lock length) are in **Management** → **Project**.

## Project vs organisation
Roles here apply to this project only. Workspace-wide policies (who may share, AI connections) are set by an administrator in the account settings.

## Common mistakes
Only the owner — and the people they allow — can share a project; ask the owner if **+ Invite** is unavailable.
