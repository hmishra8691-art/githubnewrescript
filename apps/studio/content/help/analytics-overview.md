## What it does
**Data Analytics** analyses stored responses server-side: charts, crosstabs, NPS and CSAT, segments, advanced models (conjoint, MaxDiff, drivers), findings with interpretation, dashboards, reports and PowerPoint decks.

## How to set it up
1. Open **Data Analytics** from the main navigation.
2. Pick a mode from **Modes**: **Overview** (the headline picture), **Explore** (pick variables, see charts, filter), **Architect** (the full builder), **Present** (reports and decks).
3. **Start something**: **Create analysis**, **Create crosstab**, **Create chart**, **NPS / CSAT**, **Create report**, **Define segments**.
4. **Ask in words** proposes an analysis from a sentence for you to review.
5. Export: **Excel** for tables, **PowerPoint** for decks, images for charts; reports can be shared.

## Common mistakes
Analysing the wrong dataset — check **Dataset** (all complete responses vs the clean dataset) before reading results.
