## What it does
A ResLens.ai project holds one survey: its questions, logic, design files, translations, responses and analysis. You can build it question by question in the Studio, generate it from a brief in Intelligent Mode, or import an existing questionnaire.

## How to set it up
1. On **Projects**, choose **New survey** (blank or from a template) and give it a name.
2. The project opens in the Studio. Pick how you want to program it — you can switch at any time from the **Mode** menu:
   - **Studio** — build visually, question by question.
   - **Intelligent** — describe what you want in plain language and approve each change.
   - **Grid**, **Architect** and **Flow** — high-speed tables, full-detail control, and a visual map of routing.
3. In **Programming** → **Questions**, use **+ Add question** to add questions and **+ Add block** to group them. Select a question to edit its settings in the properties panel on the right.
4. Arrange pages and blocks in **Programming** → **Survey Flow**.
5. Click **Preview** to see the survey as respondents will, and **Test Survey** to run a test version with real routing.

## Example
A short concept test: a screener (age, category usage), five concept-rating questions in one block, and an open end. Build the screener, add a skip rule that ends the survey for non-users, then preview it.

## Common mistakes
- Programming logic before the questions it depends on exist — add the questions first, then the rules.
- Forgetting that respondents only see published changes: edits stay in your draft until you save a version and publish it.

## Alternatives
- **Intelligent Mode** can draft the whole questionnaire from a research objective or hypothesis — see “Use Intelligent Mode”.
- An existing questionnaire (Qualtrics QSF, Decipher, Word, Excel, PDF) can be imported from Intelligent Mode's attach menu.
