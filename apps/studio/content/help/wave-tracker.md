## What it does
**Wave tracker** brings a tracker's waves together — uploaded files from wherever they were fielded, or this survey's live completes — matches each wave's variables to the baseline (renamed variables, changed wording or scales), and tests each KPI wave on wave, against the baseline and for trend. It also checks whether a change comes from a different sample (composition) rather than real movement.

## How to set it up
1. Open **Results** → **Wave tracker**.
2. Add waves: **Upload a wave (CSV / Excel)**, or **Add this survey's live data**. The lowest order is the baseline.
3. Review the mapping to the baseline; change any match by hand.
4. Choose KPIs (**Suggest KPIs** reads them from the baseline), composition checks (age, gender, region…) and an optional segment breakdown.
5. Read the results: each KPI's chart and table with verdicts — genuine change, sample composition, not comparable (the question changed), or no significant change. **Download CSV** for the comparison.

## Common mistakes
Comparing across a scale change (5- to 7-point) — the tracker marks it not comparable rather than testing it.
