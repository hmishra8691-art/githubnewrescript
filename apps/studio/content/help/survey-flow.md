## What it does
**Survey Flow** is the survey's running order, top to bottom: blocks of questions, and the elements around them — branches, loops, randomizers, embedded data, quota checks, redirects and endings.

## How to set it up
1. Open **Programming** → **Survey Flow**.
2. Use **+ Add block** to add a block, and **+ Add element** between items to insert **Embedded data**, **Branch / condition**, **Randomizer**, **Loop**, **Quota check**, **Redirect** or **End of survey**.
3. Drag cards to reorder, or use **Move up**, **Move down**, **Move into…** and **Duplicate** from a card's **More actions**.
4. Edit a block's questions in **Programming** → **Questions**, where each block lists its questions; page breaks split a block into pages.
5. **Flow** mode (Mode menu) shows the same survey as a visual map of routing.

## Common mistakes
- A block that appears twice in the flow (once in a branch and once after it).
- An ending placed before blocks that should still run.
