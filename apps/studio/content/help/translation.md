## What it does
**Translation** keeps every language version of the survey over one definition: AI, manual or hybrid translation, locale formats, right-to-left direction, routing respondents to their language, and translation files for translators.

## How to set it up
1. Open **Research Tools** → **Translation**.
2. Choose the **Translation mode** — **Hybrid — AI first, then review (recommended)**, **AI translation** or **Manual translation** — and click **+ Add languages**.
3. Set each language's **Locale / dialect**, how it is **Shown to respondents as**, **Direction**, and formats; add **Notes for translators / the AI**.
4. Click **Translate**, review, and **Preview** each language.
5. Decide how respondents get their language: a **URL parameter**, an **Embedded data field**, **Country → language**, or **Rules — IF … THEN language**.
6. For external translators: **Export Excel** / **Export CSV** / **Export JSON**, then **Import file…**.

## Cost
AI translation is charged per character to the project's wallet; see “How the usage wallet works”.

## Common mistakes
Translating before the questionnaire is final — every later change needs translating again (changed text is flagged).
