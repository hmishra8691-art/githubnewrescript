## What it does
Exports deliver the responses with your variable names, labels and value labels: CSV and Excel, SPSS (.sav with labels and missing values), SAS (transport file with a program) and Stata; plus long formats for conjoint and MaxDiff choices and per-page timing.

## How to set it up
1. Open **Results** → **Data**.
2. Choose the **Dataset for table & exports:** (all, clean, or custom).
3. Choose the format, tick **Include the data dictionary** and any extras (**Per-page / per-question timing columns**), and download.
4. Save the settings with **Save preset** to reuse them.
5. **Variables .xlsx** (top bar) exports the variable dictionary alone.

## Common mistakes
Renaming variables after delivering a first file — rename in **Programming** → **Variables** before fieldwork so every file matches.
